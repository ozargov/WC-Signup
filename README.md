# WC Signup

Books CrossFit White City classes the moment signup opens, and joins the waiting list if a class is full.

- **Pick classes:** send the Telegram bot any message. It shows next week's classes; tap the ones you want, then **📌 Book**.
- **What's queued:** send the bot `/list`, or look in the [`queue`](queue/) folder.
- **Backup:** GitHub app → **Actions** → **Add booking** → **Run workflow**.
- **How it works and how to set it up:** [SETUP.md](SETUP.md).
